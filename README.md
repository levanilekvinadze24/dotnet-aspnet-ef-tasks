# 🚀 .NET / ASP.NET Core Backend Practice Collection

A curated collection of practical backend tasks built with **.NET 6 / .NET 8**, focused on real-world architecture, database access, asynchronous programming, dependency injection, and clean application design.

Some of the tasks included in this repository are based on **EPAM training program assignments**, extended and refined with additional improvements and experiments.

This repository demonstrates hands-on experience with:

- 🟣 C#
- 🌐 ASP.NET Core (MVC / Web API / Minimal API)
- 🗃 Entity Framework Core
- 🧱 ADO.NET (SQLite)
- 🔄 Async / Await (I/O bound operations)
- 🔌 Dependency Injection
- 🧾 XML / JSON Serialization
- 📝 Logging (NLog)
- 🧪 Unit Testing
- 🏗 Multilayered Architecture (DAL / BLL / UI)

---

# 📦 Included Projects

## 🏬 Multilayered Online Store (Console App)
Simulates an online store using layered architecture:
- Product management
- Guest / User / Admin functionality
- Database interaction
- Clean separation of concerns (DAL / BLL)

---

## 🌍 Country Service (Async I/O Operations)
Advanced async programming practice:
- HttpClient
- REST Countries API
- JSON serialization
- Comparison of synchronous vs asynchronous implementations
- I/O bound performance analysis

---

## 🔌 Dependency Injection & URI Serialization
Advanced DI-based console application:
- Microsoft.Extensions.DependencyInjection
- Microsoft.Extensions.Configuration
- Logging with NLog
- URI parsing & validation
- XML (XmlWriter, XmlSerializer, DOM, X-DOM)
- JSON (JsonSerializer)
- Multiple data receivers (memory / file)

---

## 🗄 Northwind Employee Service (ADO.NET)
Practice of raw database interaction using:
- Microsoft.Data.Sqlite
- CRUD operations
- Parameterized queries
- Exception handling
- SQLite in-memory database

---

## 🔍 Reflection Tasks
Exploring .NET reflection capabilities:
- Type inspection
- Field & property analysis
- Method discovery
- Constructor validation
- Interface metadata extraction

## 🛒 SportsStore ASP.NET Core Application
Full ASP.NET Core MVC application:
- Product catalog with pagination
- Category navigation
- Shopping cart
- Checkout process
- Admin CRUD management
- Entity Framework Core + SQL Server
